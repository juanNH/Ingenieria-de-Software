# G06 · Modelo completo de clases

El modelo de **todas las clases del sistema** está en [G06 - Clases completas por capa.drawio](G06%20-%20Clases%20completas%20por%20capa.drawio). Abrí ese archivo con draw.io y seleccioná sus páginas inferiores para recorrer las capas.

Contiene **155 tipos: 141 clases, 6 interfaces y 8 enumeraciones**, integrados en **29 páginas**. La primera muestra las dependencias entre capas; las siguientes desarrollan los tipos, sus miembros seleccionados y relaciones.

- [Manifiesto y trazabilidad](G06%20-%20Clases%20completas%20por%20capa.manifest.json).
- [Alcance y convenciones del modelo](../../../Docs/Modelo-clases-final.md).
- [Índice de todos los diagramas](../../README.md).
